Une table faite de fichiers a besoin d’un journalA table made of files needs a log

Un dossier de fichiers Parquet ne dit pas quels fichiers forment la table. La mesure vient du lakehouse du projet, et la réponse diffère selon que l'on choisit Delta, Iceberg ou DuckLake.A folder of Parquet files does not say which files make up the table. The measurement comes from the project lakehouse, and the answer differs depending on whether you pick Delta, Iceberg or DuckLake.

Dans un lac de données, une table n'est souvent qu'un dossier de fichiers Parquet. La question paraît simple : quels fichiers forment la table aujourd'hui ? Le dossier ne le dit pas. Une mise à jour écrit un nouveau fichier sans effacer l'ancien, une suppression aussi, et une écriture interrompue peut laisser un fichier que rien ne devrait lire.In a data lake, a table is often just a folder of Parquet files. The question sounds simple: which files make up the table today? The folder does not say. An update writes a new file without deleting the old one, so does a delete, and an interrupted write can leave a file that nothing should read.

Le projet en donne une mesure. La table des commandes du lakehouse a connu 10 opérations, de la première écriture au regroupement final. À la version 8, juste après la restauration, le disque contient 8 fichiers et le journal n'en reconnaît que 5. Lire tout le dossier ferait compter deux fois le 14 novembre, que la relance fautive avait réécrit. À la dernière version, 9 fichiers restent sur le disque pour 1 fichier actif.The project gives a measurement. The lakehouse orders table went through 10 operations, from the first write to the final compaction. At version 8, just after the restore, the disk holds 8 files and the log recognises only 5. Reading the whole folder would count 14 November twice, since the faulty rerun had rewritten it. At the latest version, 9 files remain on disk for 1 active file.

Delta Lake répond par un journal posé à côté des données : un dossier _delta_log où chaque opération ajoute un fichier numéroté, qui dit quels fichiers entrent dans la table et lesquels en sortent. Pour lire la version n, on rejoue le journal jusqu'à n. C'est ce qui permet de remonter le temps, puis de supprimer plus tard les fichiers qu'aucune version conservée ne cite.Delta Lake answers with a log placed next to the data: a _delta_log folder where each operation adds a numbered file stating which files enter the table and which leave it. To read version n, the log is replayed up to n. That is what makes time travel possible, and later lets files no retained version refers to be deleted.

Apache Iceberg répartit le travail autrement : des fichiers de métadonnées décrivent chaque instantané, et un catalogue garde l'adresse du fichier de métadonnées courant ; publier une version revient à remplacer cette adresse d'un seul coup. DuckLake, dont la version 1.0 est sortie le 13 avril 2026, range toutes ces métadonnées dans une base SQL (DuckDB, PostgreSQL ou SQLite) plutôt que dans des fichiers.Apache Iceberg splits the work differently: metadata files describe each snapshot, and a catalog holds the location of the current metadata file; publishing a version means swapping that location in one step. DuckLake, whose version 1.0 was released on 13 April 2026, keeps all this metadata in a SQL database (DuckDB, PostgreSQL or SQLite) rather than in files.

Le choix dépend de qui écrit. Un journal dans le dossier suffit tant qu'un seul moteur écrit la table. Plusieurs moteurs et plusieurs équipes demandent un catalogue, qui devient une pièce à exploiter et à sauvegarder comme une autre. Dans tous les cas, lire les fichiers sans passer par le journal ou le catalogue donne un chiffre faux, sans la moindre erreur.The choice depends on who writes. A log in the folder is enough while a single engine writes the table. Several engines and several teams call for a catalog, which then becomes one more component to run and back up. Either way, reading the files without going through the log or the catalog gives a wrong number, without any error.
