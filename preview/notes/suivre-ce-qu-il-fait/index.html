Ce qu'il a fait, dans quel ordre, à quel prixWhat it did, in what order, at what price

Pour corriger un agent, il faut savoir ce qu'il a fait. Chaque exécution du projet est enregistrée en spans OpenTelemetry : un span pour l'exécution entière, un pour chaque appel au modèle, un pour chaque appel d'outil, chacun avec son début, sa durée et ses jetons.To fix an agent you need to know what it did. Every run in the project is recorded as OpenTelemetry spans: one span for the whole run, one for each model call, one for each tool call, each recording when it started, how long it lasted and how many tokens it used.

Une exécution dépliéeOne run, unfolded

La figure 1 déplie une exécution enregistrée. Chaque barre est un span ; sa longueur est sa durée. Touchez-en une pour voir ses attributs : jetons d'entrée et de sortie, outil appelé, arguments. La colonne de droite donne la part de chaque appel au modèle dans les jetons de l'exécution, ce qui sert de coût relatif.Figure 1 unfolds a recorded run. Each bar is a span; its length is its duration. Tap one to see its attributes: input and output tokens, tool called, arguments. The right-hand column gives each model call's share of the run's tokens, which serves as a relative cost.

Aller plus loinGoing further

En vraie grandeurAt full scale

Chaque exécution laisse deux fichiers : le flux d'événements brut de Claude Code, horodaté à l'arrivée de chaque ligne, et sa traduction en OTLP/JSON, le format d'échange d'OpenTelemetry, produite avec le SDK Python officiel. Sur les 28 exécutions enregistrées, un appel au modèle a duré 3,4 secondes en moyenne, un appel d'outil 0,2 secondes.Each run leaves two files: Claude Code's raw event stream, timestamped as each line arrives, and its translation into OTLP/JSON, OpenTelemetry's exchange format, produced with the official Python SDK. Over the 28 recorded runs, a model call took 3.4 seconds on average, a tool call 0.2 seconds.

Ce qui complique en vraiWhat complicates things in practice

Les conventions GenAI d'OpenTelemetry sont encore au statut « en développement » : les noms d'attributs peuvent changer. Les arguments et les résultats des outils sont optionnels dans ces conventions, parce qu'ils contiennent des données ; les garder dans une trace, c'est lui donner les mêmes droits que ces données. Enfin, les durées mesurées ici incluent le démarrage du serveur MCP et le réseau.OpenTelemetry's GenAI conventions are still at "development" status: attribute names may change. Tool arguments and results are opt-in in these conventions, because they contain data; keeping them in a trace means giving the trace the same permissions as that data. Finally, the durations measured here include starting the MCP server and the network.

Où en est le métierWhere the trade stands

État au 14 novembre 2026. Les conventions GenAI d'OpenTelemetry ont quitté le dépôt principal pour un dépôt dédié, créé en mai 2026 ; elles restent au statut « en développement ». Elles décrivent un span « invoke_agent » pour l'exécution d'un agent, « chat » pour un appel au modèle, « execute_tool » pour un appel d'outil, et des conventions propres à MCP (méthode, session). Les jetons d'entrée et de sortie y ont leurs attributs ; les arguments et résultats des outils sont optionnels.As of 14 November 2026. OpenTelemetry's GenAI conventions have left the main repository for a dedicated one, created in May 2026; they remain at "development" status. They describe an "invoke_agent" span for an agent run, "chat" for a model call, "execute_tool" for a tool call, and MCP-specific conventions (method, session). Input and output tokens have their own attributes; tool arguments and results are opt-in.

Chez Microsoft, l'agent de données de Fabric propose des diagnostics intégrés pour suivre son comportement, et ses échanges peuvent être audités et retrouvés par Microsoft Purview (documentation du 11 mai 2026).At Microsoft, the Fabric data agent offers built-in diagnostics to follow its behaviour, and its interactions can be audited and found through Microsoft Purview (documentation of 11 May 2026).

Choix techniquesTechnical choices
  • Retenu : les spans sont produits après coup à partir du flux d'événements de Claude Code, horodaté à l'arrivée de chaque ligne, avec le SDK OpenTelemetry officiel et son encodeur OTLP.Chosen: spans are produced afterwards from Claude Code's event stream, timestamped as each line arrives, with the official OpenTelemetry SDK and its OTLP encoder.
  • Retenu : arguments et résultats d'outils gardés dans les traces du projet (données d'exemple), coupés à 4 000 caractères.Chosen: tool arguments and results kept in the project's traces (sample data), cut at 4,000 characters.
