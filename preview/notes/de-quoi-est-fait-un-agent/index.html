Une question, plusieurs toursOne question, several turns

Un agent de données répond à une question en plusieurs tours. À chaque tour, le modèle relit ce qu'il a déjà, choisit un outil, reçoit un résultat, puis décide de la suite. Ce qu'il peut faire tient dans la liste de ses outils et dans la consigne reçue au départ ; ce qu'il a fait se lit dans sa trace d'exécution.A data agent answers a question in several turns. At each turn the model rereads what it has, picks a tool, gets a result, then decides what to do next. What it can do fits in its list of tools and the instructions it received at the start; what it did can be read in its execution trace.

Ce qui complique en vraiWhat complicates things in practice

Sur le banc d'évaluation, l'agent analyste a fait en moyenne 1,7 appels d'outils par question, en 8 secondes. Chaque tour renvoie au modèle la consigne, l'historique et les résultats déjà obtenus : 9 929 jetons d'entrée en moyenne par question, d'où un coût et une durée qui croissent avec le nombre de tours. Les traces contiennent des résultats de requêtes ; elles se gardent comme des journaux, avec les mêmes droits que les données. Enfin, un agent peut se tromper avec assurance : seule une évaluation systématique dit à quel point, c'est l'objet de la note suivante.On the evaluation bench, the analyst agent made on average 1.7 tool calls per question, in 8 seconds. Each turn sends the model the instructions, the history and the results so far: 9,929 input tokens per question on average, hence a cost and a duration that grow with the number of turns. Traces contain query results; they are kept like logs, with the same permissions as the data. Finally, an agent can be confidently wrong: only systematic evaluation says how much, which is the subject of the next note.

Où en est le métierWhere the trade stands

État au 14 novembre 2026. La spécification MCP en vigueur est datée du 28 juillet 2026 : des serveurs offrent des ressources, des modèles de consignes et des outils à des clients, par messages JSON-RPC ; des extensions optionnelles ajoutent les tâches longues (Tasks) ou des éléments d'interface (MCP Apps). Le SDK Python officiel est passé en version 2 ; la classe FastMCP y est devenue MCPServer.As of 14 November 2026. The current MCP specification is dated 28 July 2026: servers offer resources, prompt templates and tools to clients through JSON-RPC messages; optional extensions add long-running tasks (Tasks) or interface elements (MCP Apps). The official Python SDK has moved to version 2; the FastMCP class became MCPServer.

Chez Microsoft, l'agent de données de Fabric (Fabric data agent) est disponible pour tous : il répond en langage naturel sur des lakehouses, des entrepôts, des modèles sémantiques Power BI et des bases KQL, en générant des requêtes SQL, DAX ou KQL de lecture seule, et plafonne ses réponses à 25 lignes et 25 colonnes (documentation du 11 mai 2026). Côté dbt, un serveur MCP officiel, installé en local ou hébergé, donne accès à la couche sémantique.At Microsoft, the Fabric data agent is generally available: it answers in natural language over lakehouses, warehouses, Power BI semantic models and KQL databases by generating read-only SQL, DAX or KQL queries, and caps its answers at 25 rows and 25 columns (documentation of 11 May 2026). On the dbt side, an official MCP server, installed locally or hosted, gives access to the semantic layer.

Choix techniquesTechnical choices
  • Retenu : le SDK Python officiel de MCP (version 2, classe MCPServer), en transport stdio, avec des annotations de lecture seule sur chaque outil.Chosen: the official MCP Python SDK (version 2, MCPServer class), over stdio, with read-only annotations on every tool.
  • Retenu : la requête est compilée par MetricFlow à partir d'une mesure et de dimensions nommées ; aucun outil n'accepte de SQL. Les filtres sont des listes de valeurs, échappées par le serveur.Chosen: the query is compiled by MetricFlow from a named measure and dimensions; no tool accepts SQL. Filters are lists of values, escaped by the server.
  • Retenu : la base est attachée en lecture seule dans une base en mémoire, parce que dbt-duckdb ouvre toujours sa base principale en écriture.Chosen: the database is attached read-only inside an in-memory database, because dbt-duckdb always opens its main database for writing.
  • Retenu : Claude Code en mode non interactif, sur l'abonnement de l'auteur, sans clé d'API ; consigne remplacée, aucun outil intégré, seul le serveur MCP du projet chargé, dans un dossier de travail vide.Chosen: Claude Code in non-interactive mode, on the author's subscription, with no API key; instructions replaced, no built-in tools, only the project's MCP server loaded, in an empty working folder.
