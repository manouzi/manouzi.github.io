De quoi est fait un agentWhat an agent is made of

Une question, plusieurs toursOne question, several turns

Un agent de données répond à une question en plusieurs tours. À chaque tour, le modèle relit ce qu'il a déjà, choisit un outil, reçoit un résultat, puis décide de la suite. La liste de ses outils et la consigne reçue au départ fixent ce qu'il peut faire. Sa trace d'exécution montre ce qu'il a fait.A data agent answers a question in several turns. At each turn the model rereads what it has, picks a tool, gets a result, then decides what to do next. Its list of tools and the instructions it received at the start set what it can do. Its execution trace shows what it did.

La figure 1 rejoue une exécution enregistrée de l'agent du projet : la question, chaque appel d'outil avec ses arguments, ce que l'outil a renvoyé, puis la réponse et son verdict. Les outils viennent d'un serveur MCP (Model Context Protocol), le protocole ouvert qui décrit comment un agent découvre des outils et les appelle.Figure 1 replays a recorded run of the project's agent: the question, each tool call with its arguments, what the tool returned, then the answer and its verdict. The tools come from an MCP server (Model Context Protocol), the open protocol that describes how an agent discovers tools and calls them.

En vraie grandeurAt full scale

Le serveur MCP du projet expose cinq outils, tous déclarés en lecture seule. Le cinquième, la couverture des ventes par canal, a été ajouté le 14 novembre 2026 après un audit : les exécutions rejouées ici ne l’avaient pas. La couche sémantique est celle de dbt, interrogée par MetricFlow : l'agent choisit une mesure, des dimensions, une période et des filtres ; la requête SQL est compilée par MetricFlow, jamais écrite par le modèle, puis exécutée sur la base du projet attachée en lecture seule. Des tests vérifient que même la connexion du serveur refuse d'écrire. Chaque exécution a été lancée par Claude Code en mode non interactif, enregistrée en entier, puis rejouée ici : le site n'appelle aucun modèle.The project's MCP server exposes five tools, all declared read-only. The fifth, sales coverage by channel, was added on 14 November 2026 after an audit: the runs replayed here did not have it. The semantic layer is dbt's, queried through MetricFlow: the agent picks a measure, dimensions, a period and filters; MetricFlow compiles the SQL query, the model never writes it, and it runs against the project's database, attached read-only. Tests check that even the server's own connection cannot write. Every run was launched with Claude Code in non-interactive mode, recorded in full, then replayed here: the site makes no model calls.

Ce qui complique en vraiWhat complicates things in practice

Sur le banc d'évaluation, l'agent analyste a fait en moyenne 1,7 appels d'outils par question, en 8 secondes. Chaque tour renvoie au modèle la consigne, l'historique et les résultats déjà obtenus : 9 929 jetons d'entrée en moyenne par question, d'où un coût et une durée qui croissent avec le nombre de tours. Les traces contiennent des résultats de requêtes ; elles se gardent comme des journaux, avec les mêmes droits que les données. Enfin, un agent peut se tromper avec assurance : seule une évaluation systématique dit à quel point, c'est l'objet de la note suivante.On the evaluation set, the analyst agent made 1.7 tool calls per question on average, taking 8 seconds. Each turn sends the model the instructions, the history and the results so far: 9,929 input tokens per question on average, so cost and latency grow with the number of turns. Traces contain query results, so they are kept like logs, with the same permissions as the data. Finally, an agent can be confidently wrong: only systematic evaluation tells you how often, and that is the subject of the next demonstration.

Où en est le métierState of practice

État au 14 novembre 2026. La spécification MCP en vigueur est datée du 28 juillet 2026 : des serveurs offrent des ressources, des modèles de consignes et des outils à des clients, par messages JSON-RPC ; des extensions optionnelles ajoutent les tâches longues (Tasks) ou des éléments d'interface (MCP Apps). Le SDK Python officiel est passé en version 2 ; la classe FastMCP y est devenue MCPServer.As of 14 November 2026. The current MCP specification is dated 28 July 2026: servers expose resources, prompt templates and tools to clients through JSON-RPC messages; optional extensions add long-running tasks (Tasks) or UI elements (MCP Apps). The official Python SDK is now at version 2, where the FastMCP class was renamed MCPServer.

Chez Microsoft, l'agent de données de Fabric (Fabric data agent) est disponible pour tous : il répond en langage naturel sur des lakehouses, des entrepôts, des modèles sémantiques Power BI et des bases KQL, entre autres sources, en générant des requêtes SQL, DAX ou KQL de lecture seule, et plafonne ses réponses à 25 lignes et 25 colonnes (documentation du 11 mai 2026). Côté dbt, un serveur MCP officiel, installé en local ou hébergé, donne accès à la couche sémantique.At Microsoft, the Fabric data agent is generally available: it answers natural-language questions over lakehouses, warehouses, Power BI semantic models and KQL databases, among other sources, by generating read-only SQL, DAX or KQL queries, and caps its answers at 25 rows and 25 columns (documentation dated 11 May 2026). On the dbt side, an official MCP server, run locally or hosted, gives access to the semantic layer.

Choix techniquesTechnical choices
  • Retenu : le SDK Python officiel de MCP (version 2, classe MCPServer), en transport stdio, avec des annotations de lecture seule sur chaque outil.Chosen: the official MCP Python SDK (version 2, MCPServer class), over stdio, with read-only annotations on every tool.
  • Retenu : la requête est compilée par MetricFlow à partir d'une mesure et de dimensions nommées ; aucun outil n'accepte de SQL. Les filtres sont des listes de valeurs, échappées par le serveur.Chosen: the query is compiled by MetricFlow from a named measure and dimensions; no tool accepts SQL. Filters are lists of values, escaped by the server.
  • Retenu : la base est attachée en lecture seule dans une base en mémoire, parce que dbt-duckdb ouvre toujours sa base principale en écriture.Chosen: the database is attached read-only inside an in-memory database, because dbt-duckdb always opens its main database for writing.
  • Retenu : Claude Code en mode non interactif comme exécuteur, avec le modèle claude-sonnet-5-5 ; consigne remplacée, aucun outil intégré, seul le serveur MCP du projet chargé, dans un dossier de travail vide.Chosen: Claude Code in non-interactive mode as the runner, with the model claude-sonnet-5-5; instructions replaced, no built-in tools, only the project's MCP server loaded, in an empty working directory.

LimitesLimits

  • Chaque question n'a été exécutée qu'une fois, et le modèle ne répond pas toujours à l'identique.Each question was run only once, and the model does not always answer identically.
  • Exécuté sur un poste avec Claude Code en mode non interactif, pas en service.Run on a laptop with Claude Code in non-interactive mode, not in production.
