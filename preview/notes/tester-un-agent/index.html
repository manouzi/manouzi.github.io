Une version, c'est trois chosesA version is three things

L'agent analyste en service tient en trois choix : une consigne, les outils de son serveur MCP et un modèle. Changer l'un des trois, c'est publier une nouvelle version. Comme pour un pipeline, chaque version repasse le même banc avant d'aller en production : les 33 questions de la session A, avec leurs réponses attendues, inchangées.The analyst agent in service comes down to three choices: a prompt, the tools of its MCP server and a model. Changing any of them means releasing a new version. As with a pipeline, every version reruns the same evaluation set before going to production: the 33 questions from session A, with their expected answers, unchanged.

La règle est écrite et enregistrée dans le dépôt avant les essais : une version candidate passe si elle ne perd pas plus de 2 questions par rapport à la version en service, à condition aussi de ne perdre aucune des questions où il faut refuser de répondre. Une valeur inventée là où il fallait dire « hors périmètre » coûte plus cher au métier qu'un refus de trop.The rule was written and committed to the repository before the tests: a candidate version passes if it loses no more than 2 questions compared with the version in service, and if it loses none of the questions where it must decline to answer. An invented value where the answer should have been "out of scope" costs the business more than one refusal too many.

Ce que la marge peut voirWhat the margin can see

Rejouer exactement la même version ne donne pas toujours les mêmes 33 réponses : le modèle varie un peu d'une exécution à l'autre. Une marge nulle bloquerait donc des versions équivalentes. Avec 2 questions de marge, soit 6 points, la barrière voit une version qui casse trois questions ou plus, par exemple un outil retiré dont dépend toute une catégorie. Elle ne voit pas une baisse réelle de quelques points : sur 33 questions, elle se confond avec le bruit, et il faudrait plusieurs centaines de questions pour la mesurer.Rerunning exactly the same version does not always give the same 33 answers: the model varies slightly from one run to the next. A zero margin would therefore block equivalent versions. With a margin of 2 questions, 6 points, the gate catches a version that breaks three questions or more, for example a removed tool that a whole category depends on. It cannot see a real drop of a few points: on 33 questions that is indistinguishable from noise, and measuring it would take several hundred questions.

Résultat sur les versions enregistrées : le modèle plus petit perd trois questions et reste bloqué ; la version sans l'outil lister_mesures passe, avec deux questions perdues et une gagnée ; l'agent d'astreinte sur le petit modèle passe, à 16/18 comme la version en service.Result on the recorded versions: the smaller model loses three questions and is blocked; the version without the lister_mesures tool passes, with two questions lost and one gained; the on-call agent on the smaller model passes, at 16/18 like the version in service.

Questions discutablesDebatable questions

La comparaison fait apparaître des questions dont la formulation laisse place à deux lectures. Les réponses attendues ont été fixées avant les essais et ne sont pas retouchées après coup : ces questions restent comptées telles quelles, et sont signalées ici.The comparison brings out questions whose wording allows two readings. The expected answers were fixed before the tests and are not edited after the fact: these questions are still counted as they are, and flagged here.

  • Q15 Quelle catégorie de produits a réalisé le plus de ventes en 2025 ? « le plus de ventes » se lit en montant ou en quantité, et la réponse « ambigu » se défend."the most sales" can be read as revenue or quantity, and "ambiguous" is a defensible answer.
  • Q16 Quel mois de 2025 a enregistré le plus de ventes ? Réponds au format AAAA-MM. même double lecture, en montant ou en quantité.the same two readings, revenue or quantity.
  • Q18 Quelle sous-catégorie de produits a réalisé le plus de ventes en 2025 ? même double lecture, en montant ou en quantité.the same two readings, revenue or quantity.
  • Q30 Quel sera le total des ventes en 2027 ? une prévision pour 2027 sort du périmètre, mais « incomplet » (période non couverte) se défend aussi.a forecast for 2027 is out of scope, but "incomplete" (period not covered) is defensible too.

En vraie grandeurAt full scale

La barrière tourne comme un contrôle du pipeline : un script relit les résultats de chaque version, applique la règle et rend « passe » ou « bloquée » avec la liste des questions perdues. Ses cas limites sont testés (marge tout juste tenue, un seul refus perdu, banc incomplet). Les 85 exécutions de cette séance ont été faites en mode non interactif, avec le même cadre qu'aux sessions précédentes.The gate runs like a pipeline check: a script reads each version's results, applies the rule and returns "passes" or "blocked" with the list of questions lost. Its edge cases are tested (margin just met, a single refusal lost, incomplete evaluation set). The 85 runs of this session were made in non-interactive mode, in the same setup as the previous sessions.

Ce qui complique en vraiWhat makes it harder in practice

Une quatrième version, avec une consigne raccourcie, était prévue pour montrer un refus perdu ; elle n'a pas été lancée, et la règle du refus n'est donc démontrée que par ses tests. Les questions discutables montrent aussi qu'un banc vieillit : une version qui lit mieux une ambiguïté peut perdre des points sur un banc écrit pour la version précédente.A fourth version, with a shortened prompt, was planned to show a lost refusal; it was not launched, so the refusal rule is only demonstrated by its tests. The debatable questions also show that an evaluation set ages: a version that reads an ambiguity better can lose points on a set written for the previous version.

Où en est le métierState of practice

État au 14 novembre 2026. Microsoft publie une action GitHub pour évaluer les agents de Foundry dans un pipeline d'intégration continue : elle compare un agent à un agent de référence et donne des intervalles de confiance. Sa documentation conseille de ne pas l'exécuter à chaque commit, pour limiter le coût. Un module de formation Microsoft Learn décrit des barrières de qualité qui comparent chaque nouvelle version à une référence avant déploiement, et rappelle qu'une dérive peut venir d'une mise à jour du modèle sans changement du code.State of practice on 14 November 2026. Microsoft publishes a GitHub Action to evaluate Foundry agents in a continuous integration pipeline: it compares an agent with a baseline agent and reports confidence intervals. Its documentation advises against running it on every commit, to limit cost. A Microsoft Learn training module describes quality gates that compare each new version with a baseline before deployment, and points out that drift can come from a model update without any code change.

Choix techniquesTechnical choices
  • Retenu : la règle (marge de deux questions, aucun refus perdu) est enregistrée dans le dépôt avant toute exécution des versions candidates, et appliquée telle quelle.Chosen: the rule (a margin of two questions, no refusal lost) is committed to the repository before any candidate version is run, and applied as is.
  • Retenu : la comparaison se fait question par question sur le même banc, plutôt que sur deux scores globaux, pour voir quelles questions changent.Chosen: the comparison is made question by question on the same evaluation set, rather than on two overall scores, to see which questions change.
  • Écarté : retoucher les réponses attendues après avoir vu les résultats. Les questions discutables sont signalées sur la page.Ruled out: editing the expected answers after seeing the results. Debatable questions are flagged on the page.

LimitesLimits

  • 33 questions : la barrière voit une version qui casse trois questions ou plus, pas une baisse de quelques points.33 questions: the gate catches a version that breaks three questions or more, not a drop of a few points.
  • La règle du refus perdu n'est démontrée que par ses tests : la version prévue pour la montrer en exécution réelle n'a pas été lancée.The lost-refusal rule is only demonstrated by its tests: the version planned to show it in a real run was not launched.
  • Quatre questions du banc se révèlent discutables ; elles sont signalées et laissées telles quelles.Four questions in the evaluation set turn out to be debatable; they are flagged and left as they are.
