Le problèmeThe problem

La demande : voir le taux de livraison des fournisseurs dans un rapport, avec la définition fixée dans la démonstration « Une promesse, quatre chiffres ». Écrire la mesure prend quelques lignes. La faire arriver juste devant le lecteur, et pouvoir revenir en arrière si elle est fausse, demande plusieurs étapes, chacune pour une raison précise.The request: show the suppliers’ delivery rate in a report, with the definition set in the demonstration “One promise, four figures”. Writing the measure takes a few lines. Getting it in front of the reader correctly, and being able to go back if it is wrong, takes several steps, each for a specific reason.

Ce changement a été fait sur le projet le 14 novembre 2026. Chaque étape a enregistré sa date, la version du code, ce qu’elle a vérifié et son résultat ; la frise ci-dessous lit cet enregistrement.This change was made on the project on 14 November 2026. Each step recorded its date, the code version, what it checked and its result; the timeline below reads that record.

Parmi les blocages, 8 viennent des tests dans le navigateur (affichage, langues, accessibilité, démonstrations) et 1 de l’étape d’envoi.Since 13 November 2026, the project has launched 78 releases. 64 completed, 9 were blocked by a check and 4 were cancelled by a more recent release. Ce qui complique, en vraiWhat makes it harder in practice

L’urgence qui saute la recette. C’est la version fautive de la frise : les contrôles automatiques ne voient que ce qu’on leur a appris à voir, et seul le contrôle de production l’a rattrapée.Urgency that skips acceptance. That is the faulty version in the timeline: automated checks only see what they were taught to see, and only the production check caught it.

Des données de recette trop propres. La recette d’ici est une copie exacte de la production, et elle a laissé passer la tolérance d’un jour, faute de ligne en retard d’un jour. Une recette utile contient aussi les cas rares, quitte à les fabriquer et à le dire.Acceptance data that is too clean. Acceptance here is an exact copy of production, and it let the one-day tolerance through for lack of a line one day late. Useful acceptance data also contains the rare cases, even if they have to be made up and labelled as such.

Un changement qui dépend d’une autre équipe. Si la colonne venait d’un système géré ailleurs, le renommage oublié arriverait sans prévenir, et la vérification de la couche sémantique serait le seul filet.A change that depends on another team. If the column came from a system managed elsewhere, the forgotten rename would arrive without warning, and the semantic layer check would be the only safety net.

Un retour arrière impossible quand des données ont été écrites. Ici, le taux est calculé à la lecture, et revenir au code précédent suffit. Une table remplie par la version fautive devrait être corrigée ou rechargée, ce qu’aucun retour du code ne fait.A rollback that is impossible once data has been written. Here the rate is computed when read, and going back to the previous code is enough. A table filled by the faulty version would need correcting or reloading, which no code rollback does.

Une annulation qui n’annule rien. Ici, la première annulation de la version fautive, mal saisie, n’a rien annulé ; la seconde a rétabli la valeur. La trace publiée garde les deux, et seul le contrôle de production a permis de voir que la première avait échoué.A rollback that rolls nothing back. Here, the first rollback of the faulty version was mistyped and undid nothing; the second restored the value. The published trace keeps both, and only the production check showed that the first had failed.

Où en est le métierState of practice

Dans Microsoft Fabric, un pipeline de déploiement compte de deux à dix étapes, trois par défaut (développement, test, production), et copie le contenu d’une étape à la suivante ; plusieurs types d’éléments, dont les rapports et modèles sémantiques Power BI, y sont encore en préversion (Microsoft Learn, page datée du 24 septembre 2026). L’intégration Git relie un espace de travail à une branche d’un dépôt Azure DevOps, GitHub ou GitHub Enterprise, hébergé dans le cloud uniquement (page datée du 1er septembre 2026).In Microsoft Fabric, a deployment pipeline has two to ten stages, three by default (development, test, production), and copies content from one stage to the next; several item types, including Power BI reports and semantic models, are still in preview there (Microsoft Learn, page dated 24 September 2026). Git integration connects a workspace to a branch of an Azure DevOps, GitHub or GitHub Enterprise repository, cloud-hosted only (page dated 1 September 2026).

Côté dbt, une intégration continue construit et teste, à chaque demande de fusion, les seuls modèles modifiés et ce qui en dépend, dans un schéma temporaire supprimé à la fusion (documentation mise à jour le 7 octobre 2026). La recette de cette page joue le même rôle avec une base entière.On the dbt side, continuous integration builds and tests, for each pull request, only the modified models and what depends on them, in a temporary schema dropped at merge (documentation updated 7 October 2026). Acceptance on this page plays the same role with a whole database.

Choix techniquesTechnical choices
  • Retenu : trois bases DuckDB pour les trois environnements, avec les mêmes modèles, plutôt que trois schémas dans une seule base, pour qu’une erreur de développement ne puisse pas toucher la production.Chosen: three DuckDB databases for the three environments, with the same models, rather than three schemas in one database, so that a development error cannot touch production.
  • Retenu : le critère d’acceptation est un nombre, vérifié par un programme, et le rapport passe en relecture.Chosen: the acceptance criterion is a number checked by a program, and the report goes through review.
  • Retenu : le contrôle de production compare le taux publié à la version précédente et retient le rapport en cas d’écart, ce qui a suffi à arrêter la version fautive.Chosen: the production check compares the published rate with the previous version and holds the report back on a gap, which was enough to stop the faulty version.

LimitesLimits

  • La séparation des tâches n’est pas mise à l’épreuve ici : demande, développement et recette relèvent du même projet.Separation of duties is not put to the test here: request, development and acceptance belong to the same project.
  • La recette tourne sur une copie exacte des données de production ; elle ne voit donc rien de ce que la production ne contient pas.Acceptance runs on an exact copy of production data, so it sees nothing that production does not contain.
  • Les trois erreurs sont rejouées sur une copie du projet, avec les mêmes contrôles, et non dans l’historique réel du dépôt.The three errors are replayed on a copy of the project, with the same checks, and not in the repository’s real history.
