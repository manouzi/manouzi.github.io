Deux agents, les mêmes questionsTwo agents, the same questions

Deux agents, le même modèle, la même consigne, les mêmes 33 questions. Le premier, l'analyste, passe par la couche sémantique du projet : des mesures définies une fois, leurs dimensions et la période couverte par les données. Le second, le témoin, reçoit le schéma brut de l'entrepôt et peut écrire le SQL qu'il veut, en lecture seule.Two agents, the same model, the same instructions, the same 33 questions. The first, the analyst, goes through the project's semantic layer: measures defined once, their dimensions and the period the data covers. The second, the baseline, gets the warehouse's raw schema and can write any SQL it likes, read-only.

Les 33 questions du banc, leur réponse attendue et le verdict des deux agents. Les réponses attendues sont calculées par le pipeline, en SQL écrit à part de la couche sémantique ; une erreur dans la couche sémantique ferait donc échouer l'analyste. Un montant est juste à 0,5 % près, un taux à 0,2 % près, un compte à l'unité ; un libellé doit être exact ; pour un piège, seul le statut compte.The bench's 33 questions, their expected answer and both agents' verdicts. Expected answers are computed by the pipeline, in SQL written separately from the semantic layer; an error in the semantic layer would therefore make the analyst fail. An amount is correct within 0.5%, a rate within 0.2%, a count to the unit; a label must be exact; for a trap, only the status counts.

Ce qui complique en vraiWhat complicates things in practice

Chaque question n'a été posée qu'une fois à chaque agent : le même agent, relancé, peut répondre autrement. Un banc de cette taille sert surtout à voir qu'une nouvelle version ne fait pas moins bien que la précédente ; c'est le sujet d'une note à venir. Les questions ambiguës n'ont pas une seule bonne réponse : la règle retenue est de demander une précision plutôt que de choisir à la place de l'utilisateur. Enfin, le coût n'est pas le même : le témoin doit d'abord découvrir les tables, leurs colonnes et le décalage des dates, ce qui allonge ses exécutions.Each question was asked only once of each agent: the same agent, run again, may answer differently. A bench this size is mostly useful to see that a new version does no worse than the previous one; that is the subject of a coming note. Ambiguous questions have no single right answer: the rule chosen is to ask for clarification rather than choose for the user. Finally, the cost is not the same: the baseline must first discover the tables, their columns and the date shift, which makes its runs longer.

Où en est le métierWhere the trade stands

État au 14 novembre 2026. Les éditeurs branchent leurs agents sur une couche de définitions plutôt que sur les tables : l'agent de données de Fabric interroge un modèle sémantique Power BI en générant du DAX, avec les droits de lecture de l'utilisateur, et ses consignes et exemples se versionnent avec Git et les pipelines de déploiement (documentation du 11 mai 2026). Le serveur MCP de dbt donne accès à la couche sémantique de dbt, en local ou hébergé. Microsoft publie aussi un serveur MCP de modélisation Power BI, limité aux opérations de modélisation.As of 14 November 2026. Vendors connect their agents to a layer of definitions rather than to tables: the Fabric data agent queries a Power BI semantic model by generating DAX, with the user's read permissions, and its instructions and examples are versioned with Git and deployment pipelines (documentation of 11 May 2026). dbt's MCP server gives access to the dbt semantic layer, locally or hosted. Microsoft also publishes a Power BI modeling MCP server, limited to modeling operations.

Choix techniquesTechnical choices
  • Retenu : attendus calculés par le pipeline, en SQL indépendant de la couche sémantique (pipeline/agent/banc.py), et régénérés avec les données.Chosen: expected answers computed by the pipeline, in SQL independent of the semantic layer (pipeline/agent/banc.py), and regenerated with the data.
  • Retenu : même modèle, même consigne, même format de réponse imposé (statut, valeur, unité, explication) pour les deux agents ; seuls les outils diffèrent.Chosen: same model, same instructions, same imposed answer format (status, value, unit, explanation) for both agents; only the tools differ.
  • Retenu : intervalle de Wilson plutôt que l'approximation normale, qui déraille près de 0 % ou de 100 % sur un petit échantillon.Chosen: the Wilson interval rather than the normal approximation, which breaks down near 0% or 100% on a small sample.
