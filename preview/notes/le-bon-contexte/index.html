Deux architectures, les mêmes questionsTwo architectures, the same questions

Deux agents, le même modèle, la même consigne, les mêmes 33 questions. Le premier, l'analyste, passe par la couche sémantique du projet : des mesures définies une fois et leurs dimensions. Le second, le témoin, reçoit la liste des tables brutes de l'entrepôt et peut écrire le SQL qu'il veut, en lecture seule. Ils diffèrent par plus d'un point, et le tableau 1 dit ce que chacun reçoit. Ce banc compare donc deux architectures, sans isoler l'effet de la couche sémantique.Two agents, the same model, the same instructions, the same 33 questions. The first, the analyst, works through the project's semantic layer: measures defined once and their dimensions. The second, the baseline, gets the list of the warehouse's raw tables and can write any read-only SQL it likes. They differ in more than one respect, and table 1 shows what each receives. This evaluation therefore compares two architectures, without isolating the effect of the semantic layer.

Question par questionQuestion by question

Seules les questions où les deux agents divergent disent lequel fait mieux. Le tableau 2 les compte pour chaque version du banc, et le test exact de McNemar porte sur ces discordances. Sa p-valeur est la probabilité d'observer un écart au moins aussi marqué si les deux agents avaient le même taux de réussite ; elle ne donne pas la probabilité que l'un soit meilleur que l'autre.Only the questions on which the two agents disagree say which one does better. Table 2 counts them for each version of the set, and the exact McNemar test is applied to these discordant pairs. Its p-value is the probability of a gap at least as marked if both agents had the same success rate; it does not give the probability that one is better than the other.

Le banc v1 comptait juste une affirmation fausseSet v1 counted a false claim as correct

Un audit extérieur, le 14 novembre 2026, a relevé l'erreur. Les ventes aux revendeurs s'arrêtent le 29 novembre 2025, celles d'internet le 28 janvier 2026. L'analyste ne recevait qu'une période, la plus large, et en concluait que 2025 était couverte en entier. Le témoin, qui interrogeait les tables, émettait une réserve, et le banc la comptait fausse. Les attendus avaient été calculés sur les mêmes tables, sans contrat de complétude.An external audit, on 14 November 2026, found the error. Reseller sales stop on 29 November 2025, internet sales on 28 January 2026. The analyst only received one period, the widest, and concluded that 2025 was fully covered. The baseline, which queried the tables, raised a caveat, and the set counted it wrong. The expected answers had been computed on the same tables, with no completeness contract.

Ce que l'erreur enseigne : une couche sémantique distribue une définition fausse aussi bien qu'une juste. La période couverte y était déclarée une fois pour toutes les ventes ; l'analyste l'a reprise à chaque question, avec assurance, et le banc écrit à côté a fait la même erreur.What the error teaches: a semantic layer distributes a wrong definition as faithfully as a right one. The covered period was declared there once for all sales; the analyst repeated it in every answer, confidently, and the set written beside it made the same mistake.

Le banc v2 part d'un contrat écrit par canal (tableau 3), calculé par une requête directe sur les tables brutes, à part de la couche sémantique. Toutes les questions qui dépendent d'une période ont été revues, et 9 attendus changent sur 33. Une période incomplète sur un canal attend « incomplet » ; le total des lignes enregistrées reste accepté s'il est donné avec cette réserve, et une réponse qui affirme la période complète est comptée fausse. Le banc v1 reste publié tel quel.Set v2 starts from a contract written per channel (table 3), computed by a direct query on the raw tables, separately from the semantic layer. Every question that depends on a period was reviewed, and 9 expected answers out of 33 change. A period incomplete on one channel expects “incomplete”; the total of recorded rows is still accepted if given with that caveat, and an answer claiming the period is complete counts as wrong. Set v1 stays published as it was.

Ce qui complique en vraiWhat complicates things in practice

Chaque question n'a été posée qu'une fois à chaque agent et à chaque version : le même agent, relancé, peut répondre autrement. Un banc de cette taille sert surtout à voir qu'une nouvelle version ne fait pas moins bien que la précédente, c'est le sujet de la note Le tester comme on teste un pipeline. Les questions ambiguës n'ont pas une seule bonne réponse : la règle retenue est de demander une précision plutôt que de choisir à la place de l'utilisateur. Enfin, le coût n'est pas le même : le témoin doit d'abord découvrir les tables, leurs colonnes et le décalage des dates, ce qui allonge ses exécutions.Each question was asked only once of each agent and each version: run again, the same agent may answer differently. An evaluation set this size is mostly useful for checking that a new version does no worse than the previous one, the subject of the demonstration Testing it like a pipeline. Ambiguous questions have no single right answer: the rule here is to ask for clarification rather than guess on the user's behalf. Finally, the two agents do not cost the same: the baseline must first discover the tables, their columns and the date shift, which makes its runs longer.

Où en est le métierState of practice

État au 14 novembre 2026. Les éditeurs proposent de brancher leurs agents sur une couche de définitions, en plus des tables : l'agent de données de Fabric, quand on lui donne un modèle sémantique Power BI, l'interroge en générant du DAX, avec les droits de lecture de l'utilisateur, et ses consignes et exemples se versionnent avec Git et les pipelines de déploiement (documentation du 11 mai 2026). Le serveur MCP de dbt donne accès à la couche sémantique de dbt, en local ou hébergé. Microsoft publie aussi un serveur MCP de modélisation Power BI, limité aux opérations de modélisation.As of 14 November 2026. Vendors offer to connect their agents to a layer of definitions, in addition to tables: the Fabric data agent, when given a Power BI semantic model, queries it by generating DAX, with the user's read permissions, and its instructions and examples are versioned with Git and deployment pipelines (documentation dated 11 May 2026). dbt's MCP server gives access to the dbt semantic layer, locally or hosted. Microsoft also publishes a Power BI Modeling MCP server, limited to modelling operations.

Choix techniquesTechnical choices
  • Retenu : attendus calculés par le pipeline, en SQL indépendant de la couche sémantique (pipeline/agent/banc.py), et régénérés avec les données. En v2, les attendus sont revus selon un contrat de complétude par canal (pipeline/agent/couverture.py).Chosen: expected answers computed by the pipeline, in SQL independent of the semantic layer (pipeline/agent/banc.py), and regenerated whenever the data is. In v2, expected answers are reviewed against a per-channel completeness contract (pipeline/agent/couverture.py).
  • Retenu : même modèle, même consigne, même format de réponse imposé (statut, valeur, unité, explication) pour les deux agents. Les outils diffèrent, et avec eux les définitions, le périmètre et la couverture connue.Chosen: same model, same instructions, same imposed answer format (status, value, unit, explanation) for both agents. The tools differ, and with them the definitions, the scope and the known coverage.
  • Retenu : la comparaison question par question, par le test exact de McNemar sur les discordances ; l'intervalle de Wilson reste affiché pour chaque taux pris seul.Chosen: question-by-question comparison, with the exact McNemar test on the discordant pairs; the Wilson interval is still shown for each rate taken alone.

LimitesLimits

  • Deux architectures comparées : outils, définitions, périmètre et couverture changent ensemble. L'essai qui les séparerait, une ablation à trois bras (par exemple le témoin avec les noms complets des tables et l'outil de couverture), n'a pas été lancé.Two architectures compared: tools, definitions, scope and coverage change together. The trial that would separate them, a three-arm ablation (for example the baseline with full table names and the coverage tool), has not been run.
  • 33 questions écrites à la main pour ce banc : ce n'est pas un échantillon des questions futures.33 questions written by hand for this set: they are not a sample of future questions.
  • Une seule exécution par question et par version : relancé, le même agent peut répondre autrement.A single run per question and per version: run again, the same agent may answer differently.
