Diagnostiquer et proposer, puis attendreDiagnose and propose, then wait

La nuit, la chaîne du projet peut échouer de six façons que le pipeline sait détecter. Un agent d'exploitation lit le journal de la nuit, l'origine des tables, les volumes et les durées habituelles, puis propose un diagnostic et une première action. Il n'a aucun outil pour agir : la proposition attend une validation humaine.At night the project's pipeline can fail in six ways that the pipeline detects. An operations agent reads the night's log, the lineage of the tables, row volumes and usual run times, then proposes a diagnosis and a first action. It has no tool that can act: the proposal waits for human approval.

Une panne, une proposition, une décisionA failure, a proposal, a decision

Choisissez une nuit en panne : la figure 1 montre le journal tel que l'agent l'a lu, son diagnostic, l'action qu'il propose et sa justification. L'action ne s'applique que si vous la validez. Pour vivre la même situation sans agent, l'exercice « Une nuit d'astreinte » est dans la note sur l'orchestration.Pick a failed night: figure 1 shows the log as the agent read it, its diagnosis, the action it proposes and its reasoning. The action is applied only if you approve it. To go through the same situation without an agent, try the exercise "A night on call" in the demonstration on orchestration. En vraie grandeurAt full scale

Le banc compte 18 nuits en échec : les six pannes, trois variantes chacune (tâche visée, heure du constat, fichier arrivé ou non). Les journaux suivent le graphe réel de la chaîne, 52 tâches, avec les messages que le code du pipeline écrit. Le diagnostic attendu et les premières actions acceptées sont fixés à l'avance, dans pipeline/agent/pannes.py.The evaluation set has 18 failed nights: the six failure types, three variants each (affected task, time of detection, whether the file arrived). The logs follow the pipeline's real task graph (52 tasks) and use the messages the pipeline code actually writes. The expected diagnosis and the accepted first actions are fixed in advance, in pipeline/agent/pannes.py.

Ce qui complique en vraiWhat complicates things in practice

Plusieurs premières actions peuvent être défendables : bloquer l'actualisation avant de corriger un lot en double est prudent, rejouer la date tout de suite l'est aussi. Le banc accepte les deux, et le dit. Un agent qui propose sans agir garde l'humain au centre, mais le ralentit la nuit ; laisser l'agent relancer seul une tâche après une panne passagère serait le premier pas vers plus d'autonomie, à décider règle par règle. Deux faits sur ce banc lui-même : la liste des premières actions acceptées a été révisée une fois, après un premier essai et avant la série complète (heure du constat avancée à 04 h 30, « bloquer l'actualisation » acceptée pour un lot en double) ; et l'un des journaux fabriqués contenait une ligne d'avertissement mal horodatée, que l'agent a relevée dans sa justification. Rien n'a été relancé : les résultats sont ceux de la série enregistrée.More than one first action is defensible: blocking the refresh before fixing a duplicate batch is cautious, and so is replaying the date straight away. The evaluation set accepts both, and says so. An agent that proposes without acting keeps the human at the centre, but slows things down at night; letting the agent rerun a task on its own after a transient failure would be a first step towards more autonomy, to be decided rule by rule. Two facts about this evaluation set itself: the list of accepted first actions was revised once, after a first trial and before the full series (detection time moved to 04:30, "block the refresh" accepted for a duplicate batch); and one of the synthetic logs contained a warning line with a wrong timestamp, which the agent pointed out in its reasoning. Nothing was rerun: the results shown come from the recorded series.

Où en est le métierState of practice

État au 14 novembre 2026. Microsoft propose en préversion un agent d'exploitation pour les pipelines de Data Factory dans Fabric : sur une exécution en échec, le bouton « Investigate » donne l'activité fautive, la cause probable et les prochaines étapes (documentation du 2 septembre 2026). La documentation de l'agent de données de Fabric recommande, de son côté, des voies d'escalade vers un humain pour les demandes sensibles. L'OWASP range la validation humaine des actions à risque parmi les parades à l'injection.As of 14 November 2026. Microsoft offers, in preview, an operations agent for Data Factory pipelines in Fabric: on a failed run, the "Investigate" button shows the failing activity, the likely cause and suggested next steps (documentation dated 2 September 2026). The Fabric data agent documentation, for its part, recommends escalation paths to a human for sensitive requests. OWASP lists human approval of risky actions among its countermeasures against injection.

Choix techniquesTechnical choices
  • Retenu : un serveur MCP à part pour l'agent d'exploitation, en lecture seule, sans aucun outil d'action ; l'action proposée n'est appliquée qu'après validation humaine.Chosen: a separate MCP server for the operations agent, read-only, with no action tool at all; the proposed action is applied only after human approval.
  • Retenu : un banc de nuits construites sur le vrai graphe de la chaîne (52 tâches), avec les messages d'erreur écrits par le code du pipeline, et des attendus fixés avant les exécutions.Chosen: an evaluation set of nights built on the pipeline's real task graph (52 tasks), with the error messages the pipeline code writes, and expected results fixed before the runs.
  • Retenu : la notation accepte plusieurs premières actions quand le métier les défend toutes deux, et la liste est publiée avec le banc.Chosen: grading accepts several first actions when operations practice supports both, and the list is published with the evaluation set.

LimitesLimits

  • 18 nuits fabriquées sur le vrai graphe de la chaîne, pas des pannes réelles.18 simulated nights built on the pipeline's real graph, not real failures.
  • La liste des premières actions acceptées a été révisée une fois après un essai.The list of accepted first actions was revised once after a trial.
  • Rien n'agit sur une vraie chaîne : l'action validée est seulement affichée.Nothing acts on a real pipeline: the approved action is only displayed.
