Diagnostiquer, proposer, attendreDiagnose, propose, wait

La nuit, la chaîne du projet peut échouer de six façons que le pipeline sait détecter. Un agent d'exploitation lit le journal de la nuit, l'origine des tables, les volumes et les durées habituelles, puis propose un diagnostic et une première action. Il n'a aucun outil pour agir : la proposition attend une validation humaine.At night the project's chain can fail in six ways the pipeline can detect. An operations agent reads the night's log, the lineage of the tables, the volumes and the usual durations, then proposes a diagnosis and a first action. It has no tool to act: the proposal waits for human approval.

Ce qui complique en vraiWhat complicates things in practice

Plusieurs premières actions peuvent être défendables : bloquer l'actualisation avant de corriger un lot en double est prudent, rejouer la date tout de suite l'est aussi. Le banc accepte les deux, et le dit. Un agent qui propose sans agir garde l'humain au centre, mais le ralentit la nuit ; laisser l'agent relancer seul une tâche après une panne passagère serait le premier pas vers plus d'autonomie, à décider règle par règle. Deux faits sur ce banc lui-même : la liste des premières actions acceptées a été révisée une fois, après un premier essai et avant la série complète (heure du constat avancée à 04 h 30, « bloquer l'actualisation » acceptée pour un lot en double) ; et l'un des journaux fabriqués contenait une ligne d'avertissement mal horodatée, que l'agent a relevée dans sa justification. Rien n'a été relancé : les résultats sont ceux de la série enregistrée.Several first actions can be defended: blocking the refresh before fixing a duplicate batch is cautious, replaying the date straight away is too. The bench accepts both, and says so. An agent that proposes without acting keeps the human at the centre, but slows things down at night; letting the agent rerun a task on its own after a passing failure would be a first step towards more autonomy, to be decided rule by rule. Two facts about this bench itself: the list of accepted first actions was revised once, after a first trial and before the full series (time of the check moved to 04:30, "block the refresh" accepted for a duplicate batch); and one of the fabricated logs contained a warning line with a wrong timestamp, which the agent pointed out in its reasoning. Nothing was rerun: the results are those of the recorded series.

Où en est le métierWhere the trade stands

État au 14 novembre 2026. Microsoft propose en préversion un agent d'exploitation pour les pipelines de Data Factory dans Fabric : sur une exécution en échec, le bouton « Investigate » donne l'activité fautive, la cause probable et les prochaines étapes (documentation du 2 septembre 2026). La documentation de l'agent de données de Fabric recommande, de son côté, des voies d'escalade vers un humain pour les demandes sensibles. L'OWASP range la validation humaine des actions à risque parmi les parades à l'injection.As of 14 November 2026. Microsoft offers, in preview, an operations agent for Data Factory pipelines in Fabric: on a failed run, the "Investigate" button gives the failing activity, the likely cause and next steps (documentation of 2 September 2026). The Fabric data agent documentation, for its part, recommends escalation paths to a human for sensitive requests. OWASP lists human approval of risky actions among its countermeasures to injection.

Choix techniquesTechnical choices
  • Retenu : un serveur MCP à part pour l'agent d'exploitation, en lecture seule, sans aucun outil d'action ; l'action proposée n'est appliquée qu'après validation humaine.Chosen: a separate MCP server for the operations agent, read-only, with no action tool at all; the proposed action is applied only after human approval.
  • Retenu : un banc de nuits construites sur le vrai graphe de la chaîne (52 tâches), avec les messages d'erreur écrits par le code du pipeline, et des attendus fixés avant les exécutions.Chosen: a bench of nights built on the chain's actual graph (52 tasks), with the error messages the pipeline code writes, and expectations set before the runs.
  • Retenu : la notation accepte plusieurs premières actions quand le métier les défend toutes deux, et la liste est publiée avec le banc.Chosen: grading accepts several first actions when the trade defends both, and the list is published with the bench.
