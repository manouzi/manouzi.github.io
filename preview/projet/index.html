Deux temps : en local, puis dans le cloudTwo stages: locally, then in the cloud

Exécuté en local, en une commandeRun locally, in one command

« docker compose up --build » démarre tout le projet sur un portable : le pipeline exécute une nuit complète dans Dagster et s'arrête, puis le site et l'interface de Dagster restent ouverts. Testé depuis un dossier vide, sans données préalables."docker compose up --build" starts the whole project on a laptop: the pipeline runs a full night in Dagster and stops, then the site and the Dagster interface stay open. Tested from an empty folder, with no prior data.

docker compose up --build

Décrit pour Azure, vérifié automatiquement, pas encore déployé dans le cloudDescribed for Azure, checked automatically, not yet deployed in the cloud

Le même projet est décrit pour Azure en Bicep : registre de conteneurs, Data Lake Gen2, environnement Container Apps où la nuit devient un travail planifié et Dagster une application interne, identité managée sans mot de passe, journaux. Ce code est compilé et vérifié à chaque contrôle. Il ne crée rien pour l'instant : un vrai déploiement demande un compte Azure et coûte de l'argent.The same project is described for Azure in Bicep: container registry, Data Lake Gen2, a Container Apps environment where the night becomes a scheduled job and Dagster an internal app, a managed identity with no password, logs. This code is compiled and checked on every check run. It creates nothing for now: a real deployment needs an Azure account and costs money.

npm run check:infra
