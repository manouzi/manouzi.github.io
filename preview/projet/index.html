Le projetThe project

Une donnée d'entreprise passe par beaucoup d'étapes avant d'arriver dans un rapport, et chacune peut casser sans bruit. Ce projet construit toute la chaîne sur un jeu d'exemple, de la collecte aux agents IA, et la fait tourner chaque nuit. Il montre, sur quelque chose qui s'exécute, comment on la rend fiable et comment on la contrôle.Business data goes through many steps before it reaches a report, and any of them can break silently. This project builds the whole pipeline on sample data, from ingestion to AI agents, and runs it every night. It shows, on something that actually runs, how to make that pipeline reliable and how to monitor it.

LimitesLimits

  • Données d'exemple (AdventureWorks), pas de données d'entreprise.Sample data (AdventureWorks), not company data.
  • Rapports générés par script, pas des fichiers Power BI.Reports generated by script, not Power BI files.
  • Rien de déployé dans le cloud.Nothing deployed to the cloud.
  • Environ 1 million de lignes, donc aucune preuve de tenue en charge.About 1 million rows, so no evidence of how it holds up under load.
  • Agents évalués sur 33 questions et 18 nuits : les intervalles restent larges.Agents evaluated on 33 questions and 18 nights: the intervals remain wide.

Deux temps : en local, puis dans le cloudTwo stages: locally, then in the cloud

Exécuté en local, en une commandeRuns locally with one command

Le projet démarre en une commande sur un portable, avec Docker Compose : le pipeline exécute une nuit complète dans Dagster et s'arrête, puis le site et l'interface de Dagster restent ouverts. Ce démarrage a été essayé depuis un dossier vide, sans données préalables.The project starts with one command on a laptop, using Docker Compose: the pipeline runs a full night in Dagster and stops, then the site and the Dagster UI stay open. This start-up was tested from an empty folder, with no existing data.

Décrit pour Azure, vérifié automatiquement, pas encore déployé dans le cloudWritten for Azure, checked automatically, not yet deployed to the cloud

Le même projet est décrit pour Azure en Bicep : registre de conteneurs, Data Lake Gen2, environnement Container Apps où la nuit devient un travail planifié et Dagster une application interne, identité managée sans mot de passe, journaux. Ce code est compilé et vérifié à chaque contrôle. Il ne crée rien pour l'instant : un vrai déploiement demande un compte Azure et coûte de l'argent.The same project is defined for Azure in Bicep: container registry, Data Lake Gen2, a Container Apps environment where the nightly run becomes a scheduled job and Dagster an internal app, passwordless managed identity, logs. This code is compiled and validated on every CI run. It creates nothing for now: a real deployment needs an Azure account and costs money.
